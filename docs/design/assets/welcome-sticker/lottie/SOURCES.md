# Welcome stickers from LottieFiles — sources and licence

Every animation below was downloaded on 2026-10-07 from its LottieFiles page, where it is
marked **free** under the **Lottie Simple License** (https://lottiefiles.com/page/license):
free for commercial use in apps and websites, modification allowed, attribution not
required (credited here anyway). The licence does NOT allow redistributing the files as
standalone animations or reselling them — they ship only inside Yahora, rendered to WebP.

Each `<id>.json` is the animation from the page's `.lottie` file, with any images inlined
so it renders on its own.

**Edits made to the originals** (the licence allows modification):
- `bear`: removed the full-frame white background layer ("White Solid 6"), which drew a
  white square behind the bear, and a stray "GN" text layer inside the right leg, which
  flickered as a few pixels of text in some frames. `../build_stickers.py` renders it to `../out/<id>.webp`.
